Overview

A constraint-based automated scheduling web application for faculty and class allocation, built with Django. Instead of manually juggling faculty availability, room capacity and course requirements on a spreadsheet, the system solves for a conflict-free timetable automatically.

Purpose — Why This Project Exists

Manually building a university timetable means reconciling dozens of overlapping constraints — faculty availability, room capacity, course sections and time-slot clashes — which is slow and error-prone every single term. This system exists to encode those constraints once and let an automated solver produce a conflict-free schedule instead of redoing the puzzle by hand each semester.

Key Features

Constraint-Based Scheduling — automatically resolves faculty, room and course conflicts.
Faculty & Class Allocation — assigns instructors and sections to conflict-free slots.
Django Backend — admin panel for managing courses, rooms and schedules.

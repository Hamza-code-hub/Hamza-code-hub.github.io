Overview

A Selenium + BeautifulSoup based automation tool for profile scraping and connection workflows, built to support structured data collection for outreach campaigns.

Purpose — Why This Project Exists

Manually researching and logging profile data for outreach doesn't scale past a handful of contacts a day. This tool exists to automate the repetitive browsing-and-copying work — navigating profiles and structuring the resulting data — so outreach efforts can work from a organized dataset instead of ad-hoc manual research.

Overview

A hybrid deep-learning intrusion detection architecture combining TabNet and Transformers, trained and evaluated on the CIC-IDS 2017 cybersecurity dataset. Attention-based feature learning improves classification of malicious network-traffic patterns, with the detection model deployed via Docker and Kubernetes for scalable, real-time monitoring across critical infrastructure nodes.

Purpose — Why This Project Exists

Traditional signature-based intrusion detection only catches attacks it has already seen — it misses novel or evolving network-traffic patterns that critical infrastructure is increasingly targeted with. This project exists to combine TabNet's strength on structured tabular traffic features with Transformer attention over sequence patterns, so the system generalizes better to attack behavior it hasn't explicitly been trained on.
